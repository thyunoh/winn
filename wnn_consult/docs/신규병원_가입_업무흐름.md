# 신규병원 가입 업무흐름 (신청 → 날인 → 승인 → 계약 → 보관)

2026-08-19 작성. 근거문서 : `위너넷 적정성 컨설팅 의뢰서+원격연결(2026년).hwp`
DB : [docs/sql/join/](sql/join/)

## 진행 범위

**1차(지금)** — 신청 → 체크 동의 → 승인 → 계약. 도장·사인 없이 돌아간다.
동의는 체크 + 이메일 본인확인으로 받고, 종이 날인이 필요한 병원은 지금처럼 서식을 출력해 받아 둔다.
스크립트는 [sql/join/TBL_JOIN_REQ_20260818.sql](sql/join/TBL_JOIN_REQ_20260818.sql) — DDL 반영 완료.

**2차(나중)** — 도장 이미지 업로드 → 동의서 연동, 완성 PDF 보관.
[sql/join/TBL_JOIN_SIGN_20260819.sql](sql/join/TBL_JOIN_SIGN_20260819.sql) 에 설계만 해 두고 ⛔ 보류.
전부 새 표라 나중에 붙여도 1차 스키마를 건드리지 않는다(`TBL_AGREE_MST` ALTER 만 그때 같이).
아래 「도장·사인」 절은 2차 이야기다.

---

## 전제 — 병원 담당자는 **데스크탑·노트북**에서 한다 (2차)

태블릿·폰이 아니다. 그래서 화면 설계가 달라진다.

- **마우스로 그리는 사인은 쓰지 않는다.** 마우스 사인은 글씨가 아니라 낙서처럼 나와서
  대표자 서명으로 보이지 않는다. 노트북 터치패드는 더 나쁘다.
- **도장(직인) 이미지를 파일로 받는다.** 병원은 이미 직인 스캔 파일을 갖고 있는 경우가 많고,
  없으면 도장을 흰 종이에 찍어 스캔하거나 폰으로 찍어 PC 로 옮긴다.
- 화면은 **드래그&드롭 업로드 + 미리보기 + 위치 조정** 세 가지면 된다.
  - 받는 형식 : PNG·JPG (PNG 권장), 최대 5MB 정도
  - 흰 배경은 서버에서 투명 처리해 준다. 안 그러면 문서 위에 흰 네모가 얹힌다.
  - 미리보기에서 동의서 위에 얹힌 모습을 보여주고, 마음에 안 들면 위치·크기를 끌어서 맞춘다
    → 그 좌표가 `TBL_JOIN_SIGN.POS_X/POS_Y/POS_W`
- 스캐너·카메라가 여의치 않은 병원을 위해 **출력 → 날인 → 스캔본 업로드**(`SIGN_TYPE='3'`)도
  남겨 둔다. 지금 실무가 그 방식이라 이걸 막으면 가입이 막힌다.

## 단계별 업무

### 1단계 · 신청 (병원)

| 무엇 | 어디에 |
|---|---|
| 의뢰서 [서식1] 항목 입력 — 요양기관기호·병원명·대표자·사업자번호·주소·전화·병상수 | `TBL_JOIN_REQ` |
| 전산프로그램 정보(MASTER) — 프로그램명·ID·PW, 심평원 인증서암호 | `TBL_JOIN_REQ` (암호화) |
| PC 사용여부, 환자평가표 작성완료일, 목표점수·등급 | `TBL_JOIN_REQ` |
| 담당자 4명 — 총관리자·간호과·심사과·전산담당 | `TBL_JOIN_MGR` |
| 로그인 계정 — 이메일 + 비밀번호 | `TBL_JOIN_REQ.EMAIL / PASS_WD` |

이 시점에는 `TBL_HOSP_MST` 에 아직 병원이 없다. `HOSP_CD` 는 **신청값**일 뿐이다.

### 2단계 · 동의 (병원)

1. **[1차]** 동의서 3종을 읽고 체크 → `TBL_JOIN_AGREE`
   (동의 시점의 본문 버전·IP·일시가 남는다. 이것만으로 "언제 무엇에 동의했나" 는 증명된다)
2. **[2차]** 도장 이미지 업로드 → `TBL_JOIN_SEAL` (신청 1건에 원본 1개)
3. **[2차]** 동의서마다 「이 동의서에 날인」 → `TBL_JOIN_SIGN` (같은 도장을 가리키는 행이 서식마다 1개)

날인이 필요한 것은 **[서식2] 원격접속·DB접근**, **[서식3] 개인정보 수집·이용** 두 가지다
(`TBL_AGREE_MST.SEAL_NEED_YN='Y'`). 나머지는 체크 동의로 끝난다.

> ★ 도장 이미지를 서버가 갖고 있다는 것은 **언제든 아무 문서에나 찍을 수 있다**는 뜻이다.
> 병원이 「날인」을 누른 건만 `TBL_JOIN_SIGN` 에 행이 생기게 하고, 꺼내 쓸 때마다
> `TBL_SEAL_LOG` 에 남긴다. 이 로그가 없으면 "우리 도장이 왜 저기 찍혀 있냐"에 답할 수 없다.

### 3단계 · 검토 (위너넷)

- 스캔본이 흐리거나 도장이 잘렸는지 육안확인 → `TBL_JOIN_SEAL.CHK_YN`
- 요양기관기호가 실제 기관과 맞는지, 사업자등록증과 대표자가 일치하는지
- 미비하면 보완요청 (`REQ_STAT='20'`, 사유는 `TBL_JOIN_HIS`)

### 4단계 · 승인 (위너넷)

한 트랜잭션으로 묶는다. 순서가 중요하다.

1. `TBL_HOSP_MST` **신규 생성** — 이때 병원이 시스템에 처음 존재하게 된다
2. `TBL_USER_MST` **연계** — 대표 계정 등록(`MAIN_GU='3'` 병원관리자, `MBR_JOIN='Y'`)
3. `TBL_MEMBER_MST` 회원행 생성
4. `TBL_HOSPSIGN_MST` 로 동의 확정본 이관
5. 재사용 동의(`REUSE_YN='Y'`)한 도장은 `TBL_HOSPSEAL_MST` 로 승계
6. `TBL_JOIN_REQ.CFM_*` 에 연계키 보관, `REQ_STAT='30'`
7. **`TBL_JOIN_DOC.HOSP_CD` 채우기** ← 빼먹으면 병원 화면에서 자기 동의서가 안 보인다

### 5단계 · 계약 등록 (위너넷)

`TBL_HOSPCONT_MST` 에 계약구분(1.진료비분석 / 2.적정성평가)과 기간을 넣는다.
**계약이 없으면 로그인은 되지만 `CONACT_GB='N'` 이라 메뉴가 열리지 않는다.**
신청서에 적힌 전산프로그램 정보(OCS_*)를 여기로 옮겨 담는다.

## PDF 보관 — 위너넷도, 거래처도

종이로 하던 **"각 1부씩 나눠 갖기"** 를 그대로 전자로 옮기는 것이다. 한쪽만 갖고 있으면
나중에 "그런 동의 한 적 없다" 를 반박할 방법이 없다.

| 누가 | 무엇을 | 어디에 |
|---|---|---|
| **위너넷** | 날인 합성된 PDF 원본 | `TBL_JOIN_DOC.FILE_PATH` (★웹루트 밖) |
| **거래처(병원)** | 같은 PDF 를 메일로 받음 | `TBL_JOIN_DOC_SEND` 에 발송기록 |
| **거래처(병원)** | 로그인 후 「내 동의서」에서 다시 받기 | 같은 표, `SEND_GB='2'` |

### 왜 표가 아니라 PDF 인가

동의 여부·시각·IP 는 표에 다 있지만, 분쟁이 나면 상대가 보는 것은 **문서 한 장**이다.
"어떤 문구에 동의했는지"까지 한눈에 보이는 형태여야 한다. 그래서

- 생성 시 `DOC_HASH`(SHA-256)를 같이 저장한다 → 나중에 파일이 바뀌었는지 대조
- 본문이 개정되어도 그 PDF 는 **개정 전 문구 그대로** 남는다

### 교부는 "보냈다"까지 기록해야 교부다

메일은 반송된다. `TBL_JOIN_DOC_SEND.RESULT_GB` 가 `3.반송` 이면 교부 안 된 것이다.
승인은 났는데 안 보낸 문서는 참고쿼리 (사) 로 매일 뽑아 0 인지 본다.

### 보존기간

- 문서 자체 : 계약 종료 후 일정기간 보존 → `TBL_JOIN_DOC.KEEP_DT`
- 도장 원본 : **재사용 동의 안 한 건은 가입 완료 후 파기** → `TBL_JOIN_SEAL.DEL_DT`,
  배치로 `SEAL_IMG` 만 NULL 처리. 날인 사실과 완성본 PDF 는 그대로 둔다
- 구체적 연수는 계약·세무·개인정보 각각 기준이 달라 **위너넷 내부 방침으로 확정**해야 한다.
  표는 날짜 컬럼만 두고 값은 방침대로 채우는 구조다

## 반려·예외

| 상황 | 처리 |
|---|---|
| 이미 등록된 병원인데 신규로 신청 | 승인 막고, 기존 병원에 **사용자만** 추가 (기존 회원가입 경로) |
| 도장이 흐리거나 잘림 | `CHK_MEMO` 에 사유, `REQ_STAT='20'` 로 되돌려 재업로드 요청 |
| 도장 교체 | 원본 무효화 + **그 도장으로 찍힌 날인도 같이 무효화** — 참고쿼리 (다) |
| 동의 철회 | 계약이 살아 있으면 서비스 제공 불가 사유가 된다. 계약 해지 절차와 함께 처리 |
| 대표자 변경 | 새 대표자 명의로 동의서 재징구. 옛 동의건은 지우지 말고 남긴다 |

## 걸리기 쉬운 곳

- **웹루트 안에 파일을 두지 말 것.** `wtpwebapps` 아래 두면 URL 만 알면 남의 병원 대표자
  도장이 그대로 열린다. 다운로드는 권한 확인 후 컨트롤러 경유.
- **승인 시 `HOSP_CD` 를 문서에 안 채우면** 병원이 자기 동의서를 못 본다.
- **로컬 profile 도 운영 DB 를 본다.** 테스트 신청건이 운영에 들어간다.
