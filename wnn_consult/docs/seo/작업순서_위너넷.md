# 검색 등록 작업 순서 (위너넷 현장용)

대상: 위너넷 컨설팅 공개 페이지 5개 (`https://winner797.co.kr/wnn_consult/login/wnnpage_consult1.do` ~ `5.do`)
완료된 것: JSP 5개 서버 업로드, 제목·설명 반영, 본문 문구 반영

|---|---|---|---|
| 1 | 가비아 DNS에 TXT 레코드 추가 | 가비아 | 위너넷 담당자 (직접 로그인) |
| 2 | Search Console 소유권 확인 | 구글 Search Console | 위너넷 담당자 |

## 1단계. 가비아 DNS에 TXT 레코드 추가

1. 가비아에 로그인합니다. 위너넷 계정입니다.
2. **My가비아 → 도메인 → DNS 관리** 메뉴로 들어갑니다. (화면 이름은 조금 다를 수 있습니다.)
3. `winner797.co.kr` 도메인을 선택합니다.
4. **레코드 추가**를 누르고 아래처럼 입력합니다.
   - 유형: **TXT**
   - 호스트(이름): **@** (또는 비워 둠)
   - 값(내용): Search Console에서 복사한 `google-site-verification=...` 전체
5. 저장합니다.

> 확인 포인트: 호스트 칸에 `winner797.co.kr`을 그대로 쓰면 잘못 저장됩니다. `@` 또는 비워 두세요.

---

## 2단계. Search Console 소유권 확인

**화면 ① 시작 화면** — "Google 검색에서 실적을 추적하고 개선하세요" 화면, 가운데 **웹사이트 추가** 버튼
→ 누릅니다.

**화면 ② 속성 유형 선택** — 왼쪽 **도메인**, 오른쪽 **URL 접두어**
→ 왼쪽 **도메인**을 고르고, 입력 칸에 `winner797.co.kr`을 넣은 뒤 **계속**을 누릅니다.

**화면 ③ DNS 레코드를 통해 도메인 소유권 확인** — 레코드 유형 TXT, `google-site-verification=...` 값과 **복사** 버튼
→ **복사**를 누른 뒤 1단계로 가서 가비아에 넣습니다. 넣고 저장한 뒤 이 화면으로 돌아와 **확인**을 누릅니다.

**화면 ④ 실패(소유권 확인 실패)** — 빨간 제목 창
→ DNS가 아직 반영되지 않은 경우입니다. **확인**을 누르고 10~30분 뒤에 다시 시도합니다.
→ 계속 실패하면 가비아 레코드의 호스트·값을 다시 확인하세요.

**화면 ⑤ 성공** — 속성 화면(왼쪽 메뉴: 개요, 실적, URL 검사, Sitemaps 등)이 열립니다.

## 3단계. 사이트맵 제출

1. 왼쪽 메뉴에서 **Sitemaps(사이트맵)**를 누릅니다.
2. **새 사이트맵 추가** 칸에 아래 경로만 입력합니다. (앞의 주소는 이미 채워져 있습니다.)
   ```
   wnn_consult/sitemap.xml
   ```
3. **제출**을 누릅니다.
4. 표에서 상태를 확인합니다.
   - **성공**: 정상입니다.
   - **가져올 수 없음**: 주소를 다시 확인하세요.
   - **발견된 URL 5**: 페이지 5개가 발견되었다는 뜻입니다.

## 테스트 (모두 끝난 뒤)

### A. 자동 확인 (화면에서 바로)

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| 페이지 제목 | 페이지 열고 탭 제목 보기 | 새 제목 |
| 설명 문구 | 페이지에서 **Ctrl+U**(소스 보기) 후 `description` 검색 | 새 설명 문장 |
| 사이트맵 | https://winner797.co.kr/wnn_consult/sitemap.xml 열기 | XML 목록(5개) 표시 |
| 로봇 안내 | https://winner797.co.kr/robots.txt 열기 | `Sitemap:` 줄 포함 |
| 모바일 폭 | 브라우저 창을 휴대폰 크기로 줄이거나 개발자도구 모바일 보기 | 문단이 줄바꿈되고 가로 스크롤 없음 |

### B. 구글 도구 확인 (인터넷 브라우저에서)

1. **구조화 데이터 테스트**: https://search.google.com/test/rich-results
   - 페이지 주소를 넣고 **URL 테스트**를 누릅니다.
   - "Service" 항목이 감지되고 오류가 없으면 정상입니다.
2. **Search Console URL 검사**: 속성 화면 위쪽 검색창에 페이지 주소를 넣습니다.
   - "URL이 Google에 등록되어 있음" 또는 "색인 생성 요청"을 확인합니다.

### C. 검색 반영 확인 (며칠~몇 주 뒤)

- 구글에서 `site:winner797.co.kr/wnn_consult` 를 검색합니다.
- 검색 결과에 새 제목과 설명이 보이면 반영된 것입니다.
- **즉시 반영되지 않는 것이 정상입니다.** 보통 수일에서 몇 주 걸립니다.
- Search Console의 **색인 생성 요청**(URL 검사 화면)을 누르면 조금 빨라질 수 있습니다. 하루에 요청 수 제한이 있습니다.

## 6단계. 옛 파일 정리 (선택)

서버 `ROOT` 폴더(`/usr/share/tomcat9/webapps/ROOT/`)에 잘못 올렸던 파일이 있습니다.
- `robots.txt`
- `test.html`

실제 사이트는 이 파일을 쓰지 않으므로 지워도 됩니다. 지우기 전에 파일 이름을 한 번 확인하세요.
