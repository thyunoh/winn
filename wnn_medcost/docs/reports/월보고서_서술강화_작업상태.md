## 4. 정본 기준 — "승인 PDF가 정본, 화면은 최신 진단치" (2026-08-03 사용자 확정)

**왜 필요했나**: 화면은 열 때마다 평가표·자료를 다시 계산한다(과거월도 재산정). 그래서 승인·PDF 저장 시점과
나중에 다시 연 화면의 수치가 달라질 수 있고, 거래처가 "받은 보고서와 화면이 다르다"고 할 여지가 있었다.

**확정 기준**
1. **정본 = 승인 시점에 생성·첨부한 PDF.** 대외(거래처) 제공·문의 응대의 근거는 이 PDF 하나뿐.
2. **화면 = 최신 진단치.** 현재 상태를 보는 용도이며 정본이 아니다.
3. **차이가 생기면 시스템이 알린다.** 담당자가 재승인 여부를 판단한다. 갱신 절차 = 승인취소 → 재승인 → PDF 재생성 → 저장.
4. **거래처에는 화면을 주지 않는다(PDF만).** 편집은 물론 열람 권한도 주지 않는다 — 불일치가 그대로 노출되는 경로를 없앤다.

**구현(evalReport.jsp, JSP만 수정 · 서버·DB 변경 없음)**
- `_erApproveDiff(mst)` — 승인 시 저장된 `SNAPSHOT_JSON`(`snapshotjson`, mapper `selectEvalReportMst`에 이미 포함)과
  현재 계산을 대조. 상태가 `APPROVED` 이고 종합점수 차이 ≥ 0.05점이거나 지표별 변동이 있으면 상단에 주황 배너(`#er-apprDiff`).
  - **요약줄**: "승인(일시) 이후 수치가 달라졌습니다 — X점(등급) → Y점(등급) (▲/▼ Δ점) · 등급 변동".
  - **[변경내용 보기] 토글** (`#er-apprDetail`): 구조/의료 점수 대비 + **지표별 대조표**(지표 · 승인 당시 산출값·점수 ·
    현재 산출값·점수 · 증감). 점수와 산출값이 **둘 다** 같은 지표는 표에서 빠진다(달라진 것만 보임).
    승인 후 새로 생긴 지표는 `(승인 후 생성)`, 없어진 지표는 `(사라짐)` 으로 표기 — 자료 재적재로 지표가 통째로
    생기거나 빠지는 사례를 잡기 위함. 산출값 표기는 본문 표와 같은 `calDisp()` 를 재사용.
  - 완전히 같으면 배너 자체가 안 뜬다. **위너넷 전용**(거래처엔 화면이 없음). `.er-notice` 클래스라 인쇄·미리보기에서 자동 제외.
  - 호출 = `loadSavedTexts` 성공부 `updatePdfUi()` 직후.
  - **한계**: 스냅샷이 비어 있는 옛 승인 건은 대조 불가(배너 없음) → 한 번 재승인하면 그때부터 잡힌다.
- `er-pdfonly` — `isWinner` 아니면 `#evalReport` 에 부여해 `.er-doc`(본문) 전체를 감춘다. 남는 것은 👁 PDF보기 ·
  다운로드 배너 · 안내문뿐. PDF 가 아직 없거나 `NOR_YN='Y'`(사용운영만, PDF 미제공 규칙 2026-07-29)면
  `#er-notice` 에 "승인 확정본(PDF) 준비 중" 안내만 노출(`er-hospmsg` 클래스로 `er-hospview` 의 notice 숨김을 이 건만 해제).
