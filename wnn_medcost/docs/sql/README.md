129개가 한 폴더에 쌓여 **필요한 것을 못 찾게** 됐다. 주제별로 갈랐다.

## ⛔ 먼저 — 다시 돌리면 안 되는 것이 섞여 있다

여기 있는 것은 대부분 **한 번 돌리고 끝난 스크립트**다.
***이미 운영에 적용한 시드를 다시 돌리면 병원이 고쳐 쓴 서식이 되돌아간다.***

- **QPS 시드(`qps/seed/`)는 2026-08-15 분까지 운영 적용 완료** — 다시 돌리지 말 것.
- 파일 **머리말에 ⛔ 표시가 있으면 아직 안 돌린 것**이다(예 : `QPS_SEED_RN25_SPLIT` — 병원 답변 대기).
- DDL 은 대개 `IF NOT EXISTS` 라 다시 돌려도 무해하나, **확인 후** 실행할 것.

## 규칙

- **새 스크립트는 주제 폴더에 바로 만든다.** 루트에 두지 않는다.
- 파일 이름은 `주제_무엇_날짜.sql` — 날짜가 있어야 「언제 것인지」가 목록에서 보인다.
- ***머리말에 「무엇을·왜」와 재실행 안전 여부를 적는다.*** 반년 뒤에 그 파일을 여는 사람은 나다.
- 시드를 고쳤으면 **DB 도 같이 고친다**(반대도 마찬가지) — 한쪽만 고치면 다음 재적재 때 되돌아간다.
