## 2. 예약 번호 — **오늘 한 줄, 설계상 한 줄 더**

앞 문서(08-11) 표에 이어서 :

| 번호 | 뜻 |
|---|---|
| `900` | 점검자 사인 행/열 (기존) |
| `890` | 기간 열 머리글 입력 행 — **둘째 사인 행 우회로도 쓴다**(병동책임자·약사 반기, 5종) |
| `1000·2000` 대 | 격자 앞/뒤 열 (기존) |
| 블록×1000+항목 | LIST 행 블록 (기존) |
| **`9000` 대** | **격자 아래 자유행 표(`SUB_COLS`)의 행** — 9000+i (2026-08-13) |
| (`10000` 대) | (설계) 블록 반복 — 블록×10000+행. **아직 안 만들었다** |

`SUB_COLS` 규칙 : 서식이 열 이름을(쉼표), 문서가 행을 늘린다 · **전월복사는 안 가져온다**(그 달의 일) ·
정규화 안 함 · 근거 6종에 켜져 있다(NUR001·002·025·027·065·FAC004).

## 3. 전월복사 — **판독 메모 하나를 정정했다**

## 5. 로컬 반영 절차 — 오늘 실측으로 다듬어진 것

1. **JSP** = wtpwebapps 복사 → 즉시.
2. **자바** = 배포 classpath 로 직접 컴파일이 가장 빠르다(Eclipse 빌드 안 기다림) :
   `javac(JDK11) -encoding UTF-8 -cp "<wtpwebapps>/WEB-INF/classes;<...>/WEB-INF/lib/*;D:\egv\apache-tomcat-8.5.66\lib\servlet-api.jar"`
   → .class 를 wtpwebapps 로 복사. ⚠명령줄 `mvn` 은 여전히 금지(08-12 함정).
3. **매퍼** = wtpwebapps WEB-INF/classes 복사 → **web.xml touch** → `build` 표식 폴링.
   오늘은 touch 로 두 번 다 즉시 리로드됐다(5초). ***믿을 건 touch 가 아니라 표식이다*** — 안 바뀌면 재기동.
4. 검증 순서 ①API(curl+쿠키) ②DB ③화면. ⚠**curl 로 넣은 한글은 깨져 저장될 수 있다**(인코딩 헤더) —
   한글 왕복은 화면 저장으로 확인한다. 가짜병원 `99999998`, 끝나면 내가 만든 행만 삭제(오늘 잔여 0 확인).
