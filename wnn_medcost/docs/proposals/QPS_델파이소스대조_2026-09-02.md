# QPS — SUNWOO 델파이 원본 소스 대조 (2026-09-02)

> 지금까지 서식 385종(점검표 309 · safeRpt 76)은 **전부 SUNWOO 화면 캡처를 판독**해 옮겼다.
> 2026-09-02 에 **델파이 원본 소스**(`D:\sunwoo\sunwoo`, .pas 1,531 · .dfm 1,486)가 생겼다 —
> 캡처로는 못 보던 두 가지가 보인다 : ①**동작**(더블클릭·Enter·전월복사·서명·목록) ②**보류 서식의 진짜 구조**.
> 사용자 말대로 「검증된 소스라 사용자 위주 기능이 많다」 — 이 문서는 그것을 세어 WinCheck+ 에 무엇을 얹었고
> 무엇을 일부러 안 얹었는지 적은 것이다.

## 0. 한 장 요약

| | |
|---|---|

## 4. 이번에 이식한 것 — `qpsChk.jsp` 「편의 기능」 절 (2026-09-02)

**규칙은 SUNWOO 그대로**, 단 이 화면 원칙 둘을 지켰다 :
①**이미 적힌 값은 덮지 않는다**(전체 O·일괄 서명은 빈 칸만. SUNWOO 는 덮어쓴다 — 전월복사와 같은 원칙)
②**대상은 격자 값칸뿐**(`input[data-r]` 중 `.ltxt` 아닌 것. 사인 900·기간머리 890·자유행 9000+·이름칸·글자칸 제외 —
  글자 칸에 Enter 복사를 허용하면 대장의 이름이 사유 칸으로 번진다. SUNWOO 는 칸 **너비**로 걸렀고 우리는 `.ltxt` 로 가른다)

| 손짓 | 동작 | SUNWOO 원본 |
|---|---|---|
| 값칸 **더블클릭** | 빈→O→X→빈 | `f_switch_flag(2)` |
| 날짜/열 머리 더블클릭 | 그 **세로줄** 전부 토글(사인·890 제외) | `OnSwitchFlagLineV` |

| 사인 행 머리 더블클릭 | 빈 사인칸에 **로그인 사용자명**(`s_usernm` 쿠키) · 토·일 제외 옵션 | `OnSignLineV` + `f_signlist_V_1p(휴일 제외)` |
| 사인 칸 더블클릭 | 그 칸만(빈 칸일 때) | `f_get_sinimgEn` |

| [☐ 전체 지움] | 값칸 전부 비움 — **묻고** 한다 | 〃 |

| 「토·일 제외」 | localStorage 에 기억 | `isCheckExcludeSaturdays`·`signLine_isExcludeHolidays` |

- 구현 = 리스너를 `#ckGridWrap` 에 **한 번만 위임**(표가 다시 그려져도 살아남는다). 열 머리에 `data-col` 을 달아 세로줄 토글의 기준으로 썼다(ITEM_COL·LIST·DAY_ITEM). 날짜 격자는 기존 `data-day` 를 쓴다.
- **검증** = 배포 JSP 에서 그 블록을 그대로 꺼내 **jsdom 가짜 DOM 12경우**(scratch `sim_qpsChk_tools.js`) · JSP 함수검사(정의 94·호출 32 전부 정의) · 인라인 JS 문법 · 구조검사(div 43/43·script 2/2·JSP주석 25/25, 내 블록에 `--%>` 0).
  ⚠`docs/tools/JSP구조검사.py` 는 이 PC 에서 못 돈다 — `python` 이 **Windows 스토어 스텁**이라 「Python」만 찍고 끝난다. 같은 검사를 Node 한 줄로 대신했다(위 수치).
- ⛔**남은 것 = 브라우저로 눈으로 보기**(로컬 8080 · Eclipse **F5** 후). 특히 더블클릭이 글자 선택과 안 부딪히는지, `td.hd` 손 모양.

## 5. 일부러 안 옮긴 것 — 이유

| # | 기능 | 왜 |
|---|---|---|
