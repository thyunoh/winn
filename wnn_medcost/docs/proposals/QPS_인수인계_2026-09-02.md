## 4. 설계에서 확정한 것 (델파이로)

- **부서·병동과 양식** : SUNWOO = 한 양식 + 병동(부서)마다 자기 문서(`t_patient_chart_m.dept` = 서식 위 병동 콤보, 314종) + 통합 목록 + 병동 필터. 부서별 독립 양식은 없다(병원별 트리로 배치만). **우리 모델과 같다** — 빠진 셋을 B9 로 넣었다. [메모](QPS_부서양식구조_델파이대조_2026-09-02.md)
- **문서 저장 구조** : 키 = 병원+서식+날짜순번, 값 = 컨트롤 이름→값 K/V, Tag 규약 = 우리 INPUT_GB·예약 행번호. 전월복사는 SUNWOO 가 값까지, 우리는 틀만(유지). [대조](QPS_델파이소스대조_2026-09-02.md) §1
- **체크 선택지** : DEF/USE 표가 곧 원본의 Hint 배타 묶음(라디오). 「기타」= ETC_YN.
