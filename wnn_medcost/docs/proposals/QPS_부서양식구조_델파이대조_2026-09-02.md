# QPS 부서·병동과 양식의 관계 — 델파이 원본 대조 (2026-09-02 밤)

> 물음(사용자) : 「부서마다 독립적으로 쓰는 양식」인가, 「한 양식으로 부서마다 자기 것만 작성하고 통합해서 쓰는」 경우도 있는가.
> 설계에 중요한 요소라 SUNWOO 소스(`D:\sunwoo\sunwoo\SmartChart`)로 확정했다.

## 0. 한 줄 답

**SUNWOO 는 「한 양식 + 부서(병동)마다 자기 문서」가 기본**이다. 양식을 부서마다 따로 만들지 않는다.
문서 머리(`t_patient_chart_m`)에 `dept` 칸이 있고, 그 값은 **서식 위의 병동 콤보(`cmb_dept`)** 에서 온다.
같은 서식의 문서를 한 목록에 모아 보고(통합), 메인 화면의 부서 콤보로 걸러 본다. **314종**이 이 콤보를 갖는다(병동 224).

「부서마다 독립적인 양식」은 원본에 없다 — 대신 **병원별 트리**(`t_chartgroup_m/d`)로 어느 그룹(모듈)에 어느 서식을 둘지 병원이 정한다.
서식 하나를 두 그룹에 둘 수는 있으나 문서는 **한 풀**이다(문서 키에 그룹이 없다).

## 3. 설계에 남길 것

1. **모델은 지금 그대로** — 「한 양식 + 병동마다 문서」. 부서별 양식 복제는 *내용이 다른* 경우에만(원본에 없는 우리 장치, 유지).
2. **병동 이름을 고르게** — 자유 글자 대신 **병원별 병동 목록**에서 고르고 직접 치기도 허용. 마스터가 없으므로 SUNWOO 처럼 **그 병원 작성분의 병동값을 모아** 콤보로 주는 것이 가장 싸다(표 없이, 매퍼 한 줄). 필요하면 나중에 병원별 병동 표(`TBL_QPS_WARD`)로 승격.
3. **목록 병동 필터** — 작성 화면 문서 목록에 병동 셀렉트(전체/병동별). SUNWOO 메인 필터에 해당.
4. **병동 서식의 빈 병동 확인** — 서식 옵션 없이, 그 서식의 다른 문서가 병동을 갖고 있으면 저장 때 한 번 묻는다(막지 않음, SUNWOO 와 같음).
5. ~~전월복사~~ — 이미 같은 병동의 전월만 가져온다(확인 끝, §2).
6. 문서 수 0 인 지금이 **자유 글자 → 고르기**로 바꿀 적기다(작성분 정리 비용 없음).

※ 2~4 는 코드 작업(JSP + 매퍼 조회 1개). DDL 없음. ✅**같은 날 밤 완료**(사용자 「B9 착수」) — 병동 datalist(`selectChkWards`) · 목록 병동 필터 `#ckWardF`(`ckDocFill`) · 빈 병동 확인(`ckWardForm` = 간호 서식이거나 다른 문서가 병동을 적었으면, 한 번만 묻고 막지 않음). 검증 jsdom 16검사.
