## ★월요일 위너넷 협의 안건 (결정 필요)

1. **완료 목표를 어디로?** — 권고: ②인증 제출 가능(지표 10종 + 결재 + 인쇄)으로 1차 완성 후 실심사.
2. **결재선** — SUNWOO는 담당·팀장·부서장·이사장 **4단계**. 위너넷도 4단계로 갈지, 간소화할지.
3. **지표별 목표값·정의문구** — 정의서 분자·분모·포함/제외기준은 **병원이 채우는 항목**. 병원이 편집하는 화면을 만들지, 위너넷이 대신 세팅할지.
4. **대상 병원·병원유형** — 재활/정신(격리·강박 등)에 따라 지표 집합이 다름. 첫 적용 병원 확정.
5. **서술형 서식(계획서·회의록·FMEA·RCA) 범위** — 203종 중 다수. 서식빌더로 갈지, 우선순위 몇 종만 개별로 갈지.

## 함정 메모 (재개 시 시간 아끼려면)

- 톰캣: JSP는 즉시반영, **클래스·매퍼XML은 web.xml touch 로 리로드 강제** + BUILD 표식으로 확인 후 증상 해석.
- AJAX는 **dataType:'json'** 필수(+서버 produces). 빠뜨리면 조용히 0건.
- 마스터에 컬럼 추가하면 **읽는 SELECT 절도 같이** 고칠 것(등급필터 사라진 사고).
- `TBL_PATVAL_MST.USE_YN`은 전 행 'N' — 필터 걸면 전멸.
- `TBL_IPWON_INFO`는 입원건이 월 스냅샷마다 반복(중복제거 필수).
