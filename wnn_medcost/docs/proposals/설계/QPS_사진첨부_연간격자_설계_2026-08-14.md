## ① 사진첨부 (safeRpt 쪽) — 근거 8장

상담일지 계열 7장(h13~16·18 하단 교육자료, h23~28 사진/글상자) + w24·w54(=직원 교육 결과 보고서, **5개 부서 공통**)·w58.
공통 모양 : **「사진첨부」 라벨 칸에 2×2(또는 1~4장) 이미지 영역.**

### 설계 — 파일서버 재사용 + 표 1개

- **`TBL_QPS_SAFERPT_FILE`** 신설 : `SRP_SEQ`(PK1) · `FILE_SEQ`(PK2, 1~4) · `FILE_PATH` · `ORG_NM` · `REG_USER/DTTM`.
  저장은 **기존 sftp 파일서버 경로**(월보고서 PDF 와 같은 장치 `/sftp/upload·download.do`) 재사용 — 새 저장소를 만들지 않는다.
- **`TBL_QPS_SAFERPT_FORM.PHOTO_YN CHAR(1)`** 한 칸 추가 — 유형이 사진칸을 쓰는지. 비면 지금과 동일(기존 유형 무영향).
- 화면 : 칸 4개 격자, 클릭=업로드, 인쇄는 2×2 로 박는다. **원본 비율 유지·칸 안 맞춤**(원본이 그렇다).
- ⚠**개인정보** : 상담일지 사진에 환자·직원이 찍힐 수 있다 — 업로드 안내문구 1줄 + 파일서버 경로는 병원별 폴더.
- 더하기만 하는 DDL ⇒ **운영 선적용 안전**(08-12~14 와 같은 판단).

### 함께 정리할 것 (구현 때)

- **「직원 교육 결과 보고서」= 부서 공통 1벌 확정**(5곳째) — safeRpt 유형 `EDURPT` 하나로 넣고 부서는 본문 칸.
- h01 「문단 사이 N열×1행 집계표」 — `SUB_COLS` 1행으로 되는지 화면에서 확인, 안 되면 별도.
- ⚠w13 인사기록카드(반복행 표 **7벌**+사진)는 이 확장으로도 안 담긴다 — 개별 화면 후보로 보류.

## ② 연간(월12) 격자 — 근거 5종. ★**새 조각이 아니라 「조합 허용」이다**

| 근거 | 모양 |
|---|---|
| h30 · w19 · w23 · w25 · w55 | **항목 행 × 1~12월 열** (+앞뒤 열 : 예산·비고·점검업체) |
| 혈당측정기(진단검사 12) | **1~12월 행 × 항목 열** (월이 2줄로 쪼개짐 = `PRD_SUB`) |

### 이미 있는 것으로 담긴다 — 코드를 늘리기 전에 확인했다

- **항목×월(5종)** = 기존 **`ITEM_MONTH`** 축 그대로다(연 1장 · 항목 행 × 1~12월 열).
  예산·비고는 기존 **`PRE_COLS`/`POST_COLS`**, 계층 항목은 **`GRP_NM`/`BLK_NM`**. ⇒ **시드만 만들면 된다.**
- **월×항목(혈당측정기)** = **`DAY_ITEM` + `PRD_KIND='M'`** — v3 설계가 "MONTH_ITEM 새 축이 필요 없다"고
  이미 열어 둔 조합이다. 월 2줄 쪼갬은 `PRD_SUB='용액A,용액B'`.
  ⛔**막힌 곳 한 군데** : 서버 `chkFormSave` 가 DAY_ITEM 의 문서 단위(`PRD_GB`)를 **'M'(월)로 강제**한다 —
  연 문서가 못 된다. ⇒ **`PRD_KIND='M'` 이면 `PRD_GB='Y'` 를 허용**하는 한 줄이 필요하다(자바 → WAR 재빌드).
  화면 쪽은 `usesMm()`/문서 목록이 PRD_GB 를 이미 따르므로 따라온다(확인 후 구현).

### 순서

1. 사진첨부 DDL+매퍼+화면 → 2. `EDURPT` 유형 시드(5부서 공통) → 3. `chkFormSave` 한 줄(+화면 확인)
→ 4. 연간 격자 시드(h30·w19·w23·w25·w55 = ITEM_MONTH · 혈당측정기 = DAY_ITEM/M/Y) → 5. 화면 검증
