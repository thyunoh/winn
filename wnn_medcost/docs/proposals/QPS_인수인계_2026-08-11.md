***칸마다 갈라 줄 근거가 없다.*** 반만 복사하면 어느 칸이 복사됐는지 아무도 모른다.
⇒ 근거가 나오면 그때 갈라도 늦지 않다. **안 하는 쪽이 언제나 되돌릴 수 있는 쪽이다.**

· **전월 복사는 저장하지 않는다** — 깔아 주기만 하고 [저장]은 사람이 누른다.
· **「직전」은 만든 순서가 아니라 기간 순서**(`연+월+번호`)다. `CHK_SEQ` 로 고르면 지난달을
  나중에 고친 순간 그게 「직전」이 되어 **8월 복사가 3월 틀을 가져온다.**
· **월 생성**은 일 단위 서식만(서버가 서식에서 주기를 읽어 막는다) · 그 달의 날 수 · 있는 날은 건너뛴다.

### ★★예약 번호 — ***여기를 안 보고 칸을 더하면 값이 겹친다***

`TBL_QPS_CHK_VAL` 은 `(행, 열, 값)` 하나뿐이라, 격자가 아닌 칸은 **번호를 예약해서** 담는다.

| 번호 | 뜻 | 어디서 |
|---|---|---|
| 행·열 **900** | 점검자 사인 | 처음부터 |
| 행·열 **이름** | `TBL_QPS_CHK_ROW`(기기명) · `TBL_QPS_CHK_COL`(물질명·층) — **값이 아니라 이름이라 딴 표다** | 2026-08-12 (순서 8) |
| **행** `b*1000 + i` | `LIST` 의 **행 블록** b 의 i 번째 행 | 2026-08-12 (순서 5) |
| **열** `1000 + j` | 격자 **앞**에 붙는 j 번째 입력 열 | 2026-08-12 (순서 7) |
| **열** `2000 + j` | 격자 **뒤**에 붙는 j 번째 입력 열 | 2026-08-12 (순서 7) |

***왜 이어 붙이지 않고 띄우나*** — 격자 칸 수가 **문서마다 다르기 때문**이다.
2월은 28칸, 3월은 31칸이다. 일 뒤에 이어 붙이면 「29번 열」이 달마다 다른 것을 뜻해
**달을 바꾸는 순간 값이 옆으로 옮겨 간다.** 행도 같다 — 1블록에 한 줄 더하면 2블록이 통째로 밀린다.
⇒ **다음에 칸을 더할 때도 3000·4000 처럼 띄운다.** 그리고 이 표에 한 줄 적는다.

⚠**서식에 칸을 더할 때는 `QpsServiceImpl.copyChkForm` 도 같이 고칠 것.**
5번을 만들다 발견했다 — 4·6번에서 더한 `PRD_KIND`·`SPLIT_N`·`SPLIT_DIR` 이 **복제에서 빠져 있었다.**
파라미터가 `Map` 이라 없는 키는 예외가 아니라 **null** 이다. 화면도 로그도 아무 말이 없고
***복제본만 「모양이 왜 다르지」가 된다.*** 앞서 `DEPT_CD` 가 똑같이 날아갔던 자리다.

  확인되면 `QpsServiceImpl.ci()` 한 곳만 고치면 된다.
- 결재 **서명 이미지** — 보류 유지(텍스트 전자서명).

## 5. 오늘 겪은 함정 (다른 PC 에서 또 만날 것)

| 함정 | 증상 | 고침 |
|---|---|---|
| **MyBatis 한 글자 비교** | `NumberFormatException: For input string: "N"` | `test="x == 'Y'"` → `test='x == "Y"'`. ***여러 글자는 멀쩡해서 한 글자에서만 터진다*** |
| **공통코드는 표가 둘** | 코드값은 넣었는데 화면에 안 뜸 | `TBL_CODE_MST`(코드군) + `TBL_CODE_DTL`(코드값) **둘 다** |
| **서식코드 중복** | 새 서식이 **남의 서식을 조용히 덮어씀** | 저장이 `ON DUPLICATE KEY UPDATE` — 신규는 서버가 중복검사 |
| **증분 빌드가 오류를 숨김** | `mvn -o -q compile` 이 exit 0 인데 중복 메서드가 있었음 | **항상 `clean`** |
| **주소 숨김이 쿼리를 지움** | `?form=CENTRI` 를 화면이 못 읽음 | 서버가 모델로 내리고 JSP 가 `data-init` 으로 받는다 |
| **엑셀 CSV 한글 깨짐** | 추출 파일이 깨져 보임 | UTF-8 **BOM** 을 붙인다 |
