## h13~h15 + h16 + h18. 상담일지 계열 — ✅**5종이 한 판(공유 판)** · safeRpt 쪽

**같은 판인지 대조 결과 : 5종 전부 같은 판이다.** 레이아웃·필드가 글자 단위로 같고,
문서 제목과 상담내용 기본 문구(정형문구)만 다르다.

| 캡처 | 트리명 | 문서 제목 | 쪽수 |
|---|---|---|---|

(임상병리 f33/f38 제네릭 공유와 같은 구조). h13 만 제목이 고유.

- ②머리 : 결재란 4칸(담당/팀장/부서장/이사장) ·
  `상담일자`(년·월·일 셀렉트) + `상담자` / `인적사항` 행 = `소속/직위` + `성 명`
- ③본문(격자 아님) : `상담내용`(큰 칸) → `처리과정 및 결과`(큰 칸) → `첨부자료`(라벨 행) → **사진 첨부 칸**(2열 격자, 왼쪽 패널에 「사진사이즈 조정(마우스 휠)」 체크 — 사진 오브젝트 삽입 방식)
- 상담내용·처리과정에 **질환별 정형문구가 기본값으로 박혀 있다**(예 h13: "HbsAg(항원): negative … 예방접종이 필요함을 설명함", h15: 고혈압 교육 문구, h18: 당뇨 재검 문구). 병원은 이를 고쳐 쓴다.
- **여러 쪽 판정(h16·h18)** : 뒤 쪽은 연속 격자가 아니라 **같은 판의 섹션이 쪽 단위로 늘어난 것** —
  1쪽=머리+상담내용(전면), 2쪽=처리과정 및 결과(전면), 3쪽=첨부자료+사진 격자(2열×4행).
  h14·h15 는 같은 섹션들이 1쪽에 압축돼 있다. **쪽수 차이는 판이 아니라 내용량/사진칸 배치 차이.**
- ⑥판정 : **safeRpt 쪽** (건별 문서 · 머리 필드 + 큰 텍스트 칸 2 + 정형문구 + 사진 첨부).
  격자 축이 없다. safeRpt 유형 추가로 흡수하되 **「질환별 변형 = 제목+기본 정형문구만 다른 한 서식」**으로
  받는 것이 맞다(SUNWOO 도 실제로 한 판을 공유).
  ⚠**사진 첨부 칸**은 08-14 확장(반복행·서명란·정형문구)에 없는 조각 — safeRpt 에 이미지 첨부가 있는지 확인 필요.
- ★트리 하단에 **「재검자상담일지 - 간장질환/대사증후군/당뇨/빈혈/소화불량/신장질환」 6종 변형**이 더 있다
  (h19~h21 캡처의 사이드바에서 확인). 같은 판 + 정형문구 차이일 가능성이 높다 — **미캡처, 파트 C 대상.**

## h20. 직원건강검진 결과표 — ✅LIST × **부서별 블록 반복** (5쪽)

- ⑥**여러 쪽 판정 : 새 판이 아니라 「같은 격자 × 부서 블록 반복」** — 부서명이 블록 키.

  "블록 반복"과 달리 열 축은 그대로고 **블록 키(부서)만 도는 구조**. LIST 에 그룹(블록) 축이 있는지 확인,
  없으면 「부서」를 열로 내려 한 표로 받는 절충도 가능(원본 재현성은 떨어짐).

## 1. 재검자상담일지 6형제 (h23~h28) — ★한 판의 복제가 맞다

### ★★특별 확인 결과 — 6장 전부 같은 판이다 (면역장비 4형제 전례와 동일)

트리 이름은 `재검자상담일지 - 간장질환/대사증후군/당뇨/빈혈/소화불량/신장질환` 으로 여섯이지만,
**문서 안 제목은 여섯 장 모두 똑같이 「검진 이상자 상담일지」** 다. 칸 구성도 글자까지 같다.
다른 것은 **③미리 채워진 예시 문장**(상담내용·처리과정)과 **④하단 교육자료 블록의 내용물**뿐이다.

| 파일 | 트리 이름 | 하단 블록 내용 |
|---|---|---|
| h23 | - 간장질환 | **글상자 2개**(초록 테두리): 「1. 지방간」·「2. 간경변증」 설명 텍스트 |
| h24 | - 대사증후군 | 이미지 1장(대사증후군 관리법 포스터) |
| h25 | - 당뇨 | 이미지 1장(당뇨병 예방 식생활) |
| h26 | - 빈혈 | 이미지 1장(빈혈에 좋은 음식) |
| h27 | - 소화불량 | 이미지 1장(소화불량과 식습관) |
| h28 | - 신장질환 | 이미지 1장(크레아티닌 대사 그림) |

⇒ **시드는 서식 1벌로 묶는다.** 질환 구분은 서식이 아니라 **첨부(사진/글) 내용**이다.
(하단 블록도 h23 만 텍스트, 나머지는 이미지 — 즉 「사진첨부」 칸에 무엇을 넣었느냐의 차이지 구조가 아니다.)

### 공통 구조 (①~⑥)

- **①제목**: 검진 이상자 상담일지 (트리 이름과 다르다 — 문서 제목이 진짜)
- **②머리**: 우상단 **결재란 4칸**(담당·팀장·부서장·이사장) /
  `상담일자` 년·월·일 셀렉트 + `상담자` / `인적사항` 행 = 소속/직위 · 성명
- **③표 구조**: 격자 없음 — **라벨–값 세로 폼**
- **④항목**: 상담일자 · 상담자 · 소속/직위 · 성명 · **상담내용**(큰 칸) · **처리과정 및 결과**(큰 칸) · 첨부자료
- **⑤하단**: 교육자료 블록(사진 or 글상자 — 위 표). 좌측 도구에 `사진사이즈 조정(마우스 휠)` 체크가 있다 —
  사진칸이 이 서식의 정식 장치라는 뜻
- **⑥갈래**: **`safeRpt` 쪽** — 격자가 아예 없다. 08-14 확장분(정형문구·서명란)에 더해
  **「사진첨부」 조각**이 여기서도 필요하다(진단검사 39와 같은 요구).

## 3. h30 직원 건강유지 및 안전 관리활동 계획서

- **①제목**: 직원 건강유지 및 안전 관리활동 계획서 + 아래 `2026` 년 셀렉트 — **문서 키 = 년**
- **②머리**: 우상단 결재란 4칸(담당·팀장·부서장·이사장)
- **③표 구조**: 행 = **활동 항목(2단 계층: 분류 rowspan + 세부활동)** × 열 = **추진일정(월) 1~12** + `예산` + `비고`
- **④행 항목 (분류〔세부〕)**:
  - `직원예방접종(독감/코로나19)` (단독행)
  - `건강검진`〔`입사신체검진(잠복결핵)` · `정기신체검진`〕
  - `성희롱 및 폭언, 폭행 안전예방교육`〔`입사 O/T` · `정기교육`〕
  - `산업안전 보건 교육`〔`입사 O/T` · `정기교육`〕
  - `직원 건강증진`〔`야외활동(등산,야구장,볼링)` · `영화동호회 활동`〕
  - `특수검진`〔`방사선`〔`분기별`·`방사선 종사자 검진`〕 · `영양과(조리사,조리원)`〔`년 1회`〕 ·
    `야간 근로자`〔`배치전, 후 6개월, 1년`〕〕 — ⚠**여기만 3단 계층**
  - 비고 열 기입 예: `개인 피폭선량`(방사선 분기별) · `특수검진 2년 1회`(종사자 검진)
- **⑤하단**: 없음
- **⑥갈래**: **ITEM_DAY 꼴 + 기간축=월(1~12) 확장** — 진단검사 「12 혈당측정기(연 문서·월행)」에 이어
  **「기간축에 월을 여는 확장」의 두 번째 근거**다(그쪽은 월이 행, 이쪽은 월이 열이라 방향은 다르다).
  ⚠추가로 필요한 것 2가지: ⓐ**항목 계층 2~3단**(rowspan 그룹) ⓑ**항목별 꼬리 자유열**(예산·비고).
  연간 계획표 계열은 타 부서(감염관리 연간계획 등)에도 있을 법하니 **대조 후 조각 설계**를 권한다.

## 6. h33 직원 교육 결과 보고서 — ★진단검사 39와 같은 서식이 맞다

### ★★특별 확인 결과 — 트리 39번 판독과 일치 (「부서 공통 1벌」 근거 +1)

진단검사 판독의 39번 기술 = 「라벨-값 폼 + 결재란 4칸(담당·팀장·부서장·이사장) + 사진첨부 2×2 + 교육내용 큰 칸」.
**h33 이 이 네 요소를 전부 그대로 갖고 있다.** 부서 셀렉트도 역시 없다.
⇒ 시설 196 · 영양판 · 진단검사 39 · **보건관리자판(h33)** — **부서 공통 1벌** 판단의 근거가 넷으로 늘었다.

- **①제목**: 직원 교육 결과 보고서
- **②머리**: 결재란 4칸(담당·팀장·부서장·이사장)
- **③표 구조**: 격자 없음 — 라벨–값 세로 폼 + 사진첨부 격자 2×2
- **④항목**: `교육주제` · `교육내용`(1줄) · `교육장소` + `교육대상자`(한 행 2칸) · `교육방법` ·
  `교육일시`(년·월·일 셀렉트 + 시각 `:`) · `교육자` · **교육내용**(큰 칸) · **사진첨부**(2×2 4칸) · `첨부자료`
- **⑤하단**: 없음. ⚠좌측 `서식정보` 카운트가 **2** — 다른 장은 전부 1이었다(2쪽짜리 판일 가능성,
  화면 탭은 1 Page 뿐이라 실물 확인은 못 했다)
- **⑥갈래**: **`safeRpt` 쪽** + **「사진첨부」 조각 신설 필요**(진단검사 39 판독과 같은 결론)
