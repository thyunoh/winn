# Q&A 지식 원문 추출 스크립트 (2026-08-04)

「2022 요양병원 수가 실무교육자료」(건강보험심사평가원, 339쪽 PDF)를
적정성평가 Q&A 지식(`TBL_QNA_KB`)으로 바꾸는 변환기다.
**평소에는 쓸 일이 없다.** 원문을 다시 만들거나 다른 자료를 추가할 때만 쓴다.

## 실행 순서 (Node.js · 작업 폴더에서 순서대로)

```bash
# 0) 원문 텍스트 추출  ★-table 로 뽑는다 (아래 "왜 -table 인가" 참조)
pdftotext -enc UTF-8 -table 요양병원실무업무자료.pdf pdf_table.txt
pdftotext -enc UTF-8 -table -f 206 -l 216 요양병원실무업무자료.pdf qna02_raw.txt   # 질의응답 02절(2단 표)
pdftotext -enc UTF-8 -table -f 173 -l 200 요양병원실무업무자료.pdf adm_raw.txt     # 행정해석(2단 표)

node clean2.js       # 머리말·꼬리말·세로탭 제거 + 넓은 공백 축약 → pdf_clean2.json
node qna02.js        # 질의응답 02절 칼럼 분리          → qna02_items.json
node adm2.js         # 행정해석 칼럼 분리               → adm_items.json
node build.js        # 장·절·항목으로 나눠 지식 행 생성 → rows.json
node gen_pdf_sql.js  # 원문 지식 교체 SQL 생성          → ../../sql/TBL_QNA_pdf_rebuild_YYYYMMDD.sql
```

`pdftotext` 는 Git for Windows 에 들어 있다(`C:\Program Files\Git\mingw64\bin\pdftotext.exe`, Xpdf 4.00).

생성된 SQL 은 **`SRC_TYPE='PDF'` 행만 지우고 다시 넣는다** — 위너넷이 손질한
사내 확정지식(`SRC_TYPE='IN'`)은 건드리지 않는다.

## 왜 `-table` 인가 (★재작업 시 가장 중요)

처음에는 `-layout` 으로 뽑았는데, 원문에 표가 많아 **한 행의 값들이 서로 다른 줄로 흩어졌다.**
질병명은 이 줄, 질병코드는 아래 줄에 찍혀 화면에서 무슨 코드인지 알 수 없었다.

`-table` 은 행을 붙여 준다. 대신 낱말 사이 간격이 넓어지므로 **2칸 이상 공백을 한 칸으로 줄여**
문장을 정상화한다(`clean2.js`). 그러면 표는 "이름 코드" 한 줄로, 본문은 원래 문장으로 나온다.

## DB 에서 지식을 고친 뒤 (Export.java)

지식의 **원본은 DB**(`TBL_QNA_KB`)다. 화면도 DB 를 읽는다.
DB 에서 내용을 고쳤으면 시드 파일을 **DB 기준으로 다시 뽑아** 둔다 — 안 그러면
나중에 시드를 재적재할 때 고친 내용이 되돌아간다.

```bash
java -cp <mysql-connector.jar> Export.java     # → ../../sql/TBL_QNA_seed.sql 갱신
```

## 주의 (재작업 시 반드시 확인)

- **세로 사이드탭**: 원문 바깥쪽에 장 제목이 한 글자씩 세로로 인쇄돼 있다.
  **글자로 판별하면 안 된다** — '수','가','등','원' 같은 흔한 글자가 본문 끝에도 온다.
  여러 줄이 공통으로 마지막 글자를 두는 **칼럼 위치**로 찾아 잘라낸다(`clean2.js` cutSideTab).
- **머리말의 장 표시(Ⅰ·Ⅱ·Ⅲ)는 앞에 붙기도 뒤에 붙기도 한다.** 위치를 고정해 매칭하면
  일부 페이지에서 안 걸러지고, 그 줄이 페이지 첫 줄이 되어 **절 제목 인식이 통째로 깨진다**.
- **2단 표(연번|질의|답변)의 칼럼 경계는 표 머리글 글자 위치로 잡으면 안 된다** —
  머리글은 칸 가운데 정렬이라 본문 시작 위치와 다르다. **본문 '○' 위치의 최빈값**으로 잡는다.
  (`qna02.js` / `adm2.js` — 처음에 이걸 몰라 행정해석 분리를 포기했었다)
- **질의응답 절 제목(01.~13.)은 항상 페이지 첫 줄**에 온다. 이 조건을 빼면 번호로 시작하는
  *질문*이 절 제목으로 오인된다.
- **심볼 폰트 글자**: Wingdings 등으로 찍힌 불릿이 사용자영역(U+E000~F8FF)으로 추출돼
  화면에서 □(두부)로 깨진다. `▸`·`·`·공백으로 치환한다(`clean2.js` PUA).
- **행정해석 질의문은 400자를 넘기도 한다** → `TITLE` 컬럼(400) 초과. 제목은 줄이고
  잘린 원문은 본문 맨 앞에 `[질의]` 로 남긴다(`gen_pdf_sql.js`).
- 수술코드 목록(별표4 등)·별지 서식·전자문서 파일레이아웃은 **질문거리가 못 되어 제외**했다
  (`build.js` 의 `CH` 배열 쪽 범위와 `skip`).
